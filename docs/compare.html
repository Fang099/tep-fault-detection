LearnWhy each model gets its own threshold

Two models' scores live on different scales. A balanced model's scores are pushed toward the middle, an unweighted model's toward 1, so the same threshold of, say, 0.5 means something completely different for each. Comparing them at 0.5 would mostly compare how their scores happen to be scaled.

Fixing the false alarm rate instead asks the question an operator cares about: if I can tolerate this many false alarms, how many real faults does each model catch? Each model's threshold is chosen on the validation runs to give exactly that rate, and then recall is compared. The ROC curve shows the same comparison at every false alarm rate at once.
