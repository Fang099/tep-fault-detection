Which fault is it?

Once a fault is active, the model reads one snapshot of the 52 variables and names one of the 20 fault types. Pick a model and see which faults it recognizes, which it confuses, and how quickly it settles on the right answer.

Overall accuracy

Evaluated on every validation row where a fault is active. All 20 fault types have the same number of rows, so always guessing one fault is right 5% of the time.

LearnOne model, twenty scores

For diagnosis, logistic regression keeps a separate set of weights for every fault k. Each set turns the 52 readings into a score zk, and the softmax function turns the 20 scores into probabilities that add up to 1. The model names the fault with the highest probability:

LearnMacro-F1, worked out with these numbers

For each fault, precision asks "when the model names fault k, how often is it right?" (a column of the confusion matrix) and recall asks "of fault k's rows, how many are named correctly?" (a row). F1 combines the two, and macro-F1 averages all 20 with equal weight, so easy faults can't hide hard ones:

How quickly is the right fault named?

For each faulty validation run: minutes from the moment the fault starts until the model names the correct fault 3 times in a row. Faded bars mean this happened in only some runs.

Three correct answers in a row can also happen by chance for a fault the model barely recognizes, especially over a long run. Long delays with a low share of runs should be read as "not reliably diagnosed".
