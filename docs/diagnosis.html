Task 2 · Fault diagnosis

Which fault is it?

Once a fault is active, the model reads one snapshot of the 52 variables and names one of the 20 fault types. Pick a model and see which faults it recognizes, which it confuses, and how quickly it settles on the right answer.

1 · Overall accuracy 2 · What gets confused 3 · Fault by fault 4 · How quickly

1Overall accuracy

Evaluated on every validation row where a fault is active. All 20 fault types have the same number of rows, so the majority baseline (always guess one fault) is right 5% of the time.

2What gets confused with what

Each row is the true fault, each column the model's answer. Numbers are the percentage of that fault's rows, so a perfect model would fill only the diagonal. Click a row to see where its rows end up.

3Fault by fault

Recall per fault: the share of each fault's rows the model names correctly. The dashed line is chance (5%).

4How quickly is the right fault named?

For each faulty validation run: minutes from the moment the fault starts until the model names the correct fault 3 times in a row. Faded bars mean this happened in only some runs.

Three correct answers in a row can also happen by chance for a fault the model barely recognizes, especially over a long run. Long delays with a low share of runs should be read as "not reliably diagnosed".
