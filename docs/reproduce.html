The short version

Get the four CSV files from the Kaggle dataset afrniomelo/tep-csv into one folder, then run the two commands below. One script, tep_pipeline.py, loads and labels the data, splits it by simulation number, trains every model, picks thresholds and models on validation, runs the test once, and writes the files this website reads. A fixed seed (42) makes the split and models repeatable.

pip install -r requirements.txt
python tep_pipeline.py --data-dir path/to/csvs                # train and validate every model
python tep_pipeline.py --data-dir path/to/csvs --final-test   # once, at the end: the final test

All the data needs more memory than a free Colab session provides; training every model took more than a day on a desktop PC. The README shows a smaller run and the Colab notebook.

Results and split files

Every number on this site is read from the result files in docs/data/. The repository also has them as readable tables, so they can be checked without running anything:

  • results/: every detection and diagnosis model on validation, the final test, each fault, the end-to-end system, the learning curve and the random-split demonstration.
  • splits/: the exact 400 training and 100 validation simulation numbers.
  • exploration/: my first exploration notebook, from before the pipeline.
