LearnWhy regularization barely helps here

What it is for. A penalty pulls the weights towards zero. That makes the model a little less able to fit the training data (more bias) in exchange for weights that depend less on which rows happened to be in training (less variance). The trade pays off when a model has many weights for the amount of data, so that it starts fitting noise: overfitting.

Why there is little to gain here. Logistic regression has 52 weights (156 with history; one set per fault for diagnosis), and it trains on about 4 million rows. Even counting whole runs rather than rows, since rows of one run are strongly correlated, that is 8,400 training runs. With that much data the unpenalized weights are already pinned down precisely: there is almost no variance left for a penalty to remove, and the learning curve on the Results page shows the same thing for the best models, where even 5% of the runs gets within a few points of all of them.

What limits it instead is bias. A logistic regression can only draw one straight boundary through the readings (a weighted sum). Many faults show up as a change in how much a sensor fluctuates, or in a combination of sensors, which a straight boundary can't follow. A penalty makes the model simpler, which is the opposite of what it needs; that is why the tree models, which can bend the boundary, do much better.

Where regularization still earns its place. It would matter with far fewer runs. Even here it helps reading the model: the sensors are strongly correlated (see the correlation map), so unpenalized coefficients can trade off against each other, while ridge keeps them stable and lasso shows how few sensors are enough (the coefficient paths below). Strong lasso does hurt: once it removes sensors the model needs, performance drops.

Dividing everything by C·N doesn't change which weights win, and shows the trade-off more plainly: the average log-loss per row, plus the penalty scaled by 1 / (C·N).

Ridge divides, so a coefficient gets smaller but never reaches zero. Lasso subtracts a fixed amount, so any coefficient smaller than λ lands exactly on zero and that sensor drops out of the model.
